# Frontend

This is a React + Typescript frontend that provides users a way to manually make changes in the database without having to run SQL. There are two primary features: CRUD UI and genre annotation. Each feature should be a 'tab' that you can select to use that feature.

## CRUD UI

Each DB table should present as a physical table. The tables marked as "big" should use endpoints to paginate rows, the tables marked as "small" can load all data.
